# Amigos SMP — Survival+ v1.1

Servidor Minecraft Java para jogar com amigos mantendo a base survival, mas com progressão, comandos sociais, missões, profissões, eventos e bosses próprios.

## Base técnica
- Minecraft Java 1.21.11
- Purpur/Paper
- Java 21
- Plugin próprio `AmigosSMP`
- Maven

## Recursos
- `/amigos`, TPA, homes, spawn, RTP e parties
- Missões diárias
- Profissões e níveis
- Guardião Corrompido como boss
- Drops raros/épicos
- Eventos Caçada, Mineração e Aventura
- GitHub Actions para compilar o plugin

Veja `docs/COMANDOS.md` e `docs/ROADMAP.md` para os detalhes.
