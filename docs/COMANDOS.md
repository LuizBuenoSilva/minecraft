# Comandos — Amigos SMP v1.1

## Jogadores
- `/amigos` — abre o menu principal.
- `/tpa <jogador>` — pede teleporte.
- `/tpaccept` / `/tpdeny` — aceita ou recusa TPA.
- `/sethome [nome]`, `/home [nome]`, `/delhome [nome]` — homes.
- `/spawn` — volta ao spawn.
- `/rtp` — exploração aleatória segura.
- `/perfil [jogador]` — perfil, estatísticas e profissão.
- `/moedas` — saldo.
- `/party create|invite|accept|leave|list|chat` — grupos.
- `/missoes` — missões diárias.
- `/profissao escolher <minerador|cacador|fazendeiro|explorador>` — profissão.
- `/evento` — mostra o evento atual.
- `/boss` — mostra bosses ativos.
- `/itens` — catálogo de drops especiais.

## Administração / testes
- `/setspawn`
- `/boss summon`
- `/evento iniciar cacada`
- `/evento iniciar mineracao`
- `/evento iniciar aventura`
