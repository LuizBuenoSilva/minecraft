# Plugins complementares

O `AmigosSMP.jar` já cuida de TPA, homes, spawn, RTP, parties, moedas, missões, profissões, bosses e eventos.

Recomendados:
- **LuckPerms** — permissões.
- **CoreProtect** — histórico/rollback de grief.
- **GriefPrevention** ou **Lands** — proteção de terrenos.
- **BlueMap** — mapa 3D, se a hospedagem permitir.
- **ViaVersion/ViaBackwards** — compatibilidade de versões.
- **Geyser + Floodgate** — opcional para Bedrock.
- **Chunky** — pré-geração de chunks.

Para Terralith, Incendium e Nullscape, instale datapacks compatíveis antes de explorar grandes regiões e faça backup.
